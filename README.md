## The Othello Game
The Adversarial Search assignment uses the board game Othello as an example. Othello is a strategy board game (like Chess or Checkers) and is played on an 8x8 board between two parties. The objective of the game is for one party to have the majority of their disk color to fill up the majority of the board.

This program acts as an AI program/bot that has the ability to play Othello against an human player.
